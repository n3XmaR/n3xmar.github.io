This learning path helped me build a stronger foundation in web application security, from understanding how HTTP and web applications work to identifying and exploiting common vulnerabilities.

Through the hands-on labs, I practiced web enumeration, working with Burp Suite, and exploring vulnerabilities such as SQL Injection, XSS, and IDOR.

Alongside TryHackMe, I also studied Ibrahim Hegazy's Web Application Penetration Testing course on YouTube to deepen my understanding of web attacks and the concepts behind them.
